# PeaShops

Sign-based chest shop plugin for Minecraft Paper 1.21.1+.

The basics — sign, chest, type or click your way through item and price. Trade engine takes the lock + snapshot route so dupes basically arent a path. Dynamic pricing tied to stock, bulk discount tiers, timed sales, granular trust perms.

## Install

Drop the jar in `plugins/`, restart, done. Vault is required for the economy hook.

## Commands

`/shop` — owner stuff (tier, sale, trust, dynamic, info)
`/shopadmin` — staff stuff (reload, stats, list, remove)
